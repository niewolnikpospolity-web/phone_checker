      DEVICE COMMANDS

      Device terminal

      ADB MANUAL · FASTBOOT LIMITED

      ADB accepts manual commands for the selected authorized device, including shell commands. Fastboot supports read-only checks, reboot, and flashing only the boot or recovery partition from a local .img file.

      For ADB, enter a command such as shell getprop ro.product.model or adb shell …. Commands outside the read-only presets require confirmation.
      Only .apk files directly inside the apk_files folder are listed. ADB sends the selected file to the authorized phone after confirmation.
      Only .img files directly inside the flash_files folder are listed. Only boot and recovery can be flashed; erase and other partitions remain blocked. Use an image made for your exact device. Flashing an incompatible image can make the phone unbootable.
      Choose a command and check for connected USB devices to enable the terminal.

      ⓘ ADB commands can modify the selected phone and require confirmation when custom. Fastboot flash is limited to boot/recovery images and requires confirmation; unlock and erase commands remain disabled.
