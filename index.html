      DEVICE COMMANDS

      Device terminal

      ADB MANUAL · FASTBOOT LIMITED

      ADB accepts manual commands for the selected authorized device, including shell commands. Commands can change settings or data, so review them carefully. Fastboot remains limited to its supported read-only and reboot commands.

      For ADB, enter a command such as shell getprop ro.product.model or adb shell …. Commands outside the read-only presets require confirmation.
      Enter the full Windows path to an APK on this computer. ADB will send it to the selected phone and ask for confirmation.
      Choose a command and check for connected USB devices to enable the terminal.

      ⓘ ADB commands run on the selected authorized phone and may modify it. Every custom ADB command requires confirmation. Fastboot unlock, erase, and flash commands remain disabled.
